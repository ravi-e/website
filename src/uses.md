## Workstation Gear

- **Primary Monitor:** GIGABYTE G24F (24-inch, 1080p, 165Hz, HDR Support).
- **Audio Output:**
  - Soundcore Life Q30 &mdash; Wireless over-ear headphones for focused drafting sessions.
  - Sony WF-1000XM5 &mdash; Wireless noise-canceling earbuds for calls and commuting.
  - Creative 2.1 Speakers &mdash; Desktop audio.
- **VR Gear:** Meta Quest 3 VR Headset.

## Documentation Stack & Software

- **Documentation & Editing:** MadCap Flare, Oxygen XML Author, Confluence, DITA XML, Markdown, VS Code.
- **Docs-as-Code & Build:** Eleventy (11ty), MkDocs.
- **Version Control & Workflow:** Git, GitHub, GitHub Desktop, Jira.
- **AI & Developer Assistants:** Google Antigravity, GitHub Copilot.
- **Security & Utilities:** Bitwarden.

## Mobile & Transportation

- **Mobile Device:** Google Pixel 9 Pro.
- **Vehicle:** Ather Rizta Z (3.7 kWh battery) electric scooter with an active Pro Pack subscription.
