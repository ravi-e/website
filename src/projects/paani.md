**Paani** is a work in progress. It is an Android mobile application built with Flutter that is designed to help senior citizens track their daily water intake. It is built with accessibility in mind and follows WCAG AA compliance guidelines. The goal is to create an app that is simple and easy to use for seniors, with features that help them stay hydrated. 

I am still working on the UI and with Google crippling Antigravity's quotas, progress has slowed down. This post will be updated once I have more to show (or if Antigravity's quotas improve).
